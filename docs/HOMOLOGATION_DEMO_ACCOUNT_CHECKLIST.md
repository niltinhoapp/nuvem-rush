# Checklist da conta demo para homologação

Nunca versionar senhas, tokens, telefones ou credenciais reais.

## Preparação

- [ ] Loja demo ativa e identificada no Portal.
- [ ] App liberado para instalação pela URL oficial.
- [ ] Conta Meta/WhatsApp Business de teste aprovada.
- [ ] Número destinatário consentido para mensagem de teste.
- [ ] Plano/trial liberado sem bloqueio de pagamento.
- [ ] Dados fictícios suficientes para pedido e execução.
- [ ] Credenciais entregues somente pelo canal seguro solicitado pela Nuvemshop.

## Jornada

- [ ] Instalar pela URL oficial da Nuvemshop e aceitar permissões.
- [ ] Confirmar redirecionamento pós-instalação.
- [ ] Abrir o app pelo Admin e validar iframe/Nexo.
- [ ] Validar usuário/loja nova sem fluxos.
- [ ] Conectar WhatsApp pela janela oficial da Meta.
- [ ] Voltar ao app e atualizar status.
- [ ] Criar fluxo com gatilho e ação.
- [ ] Salvar rascunho.
- [ ] Ativar fluxo.
- [ ] Executar teste controlado e comprovar resultado/log.
- [ ] Reabrir como usuário existente e confirmar persistência.
- [ ] Desinstalar pelo Admin.
- [ ] Confirmar comportamento pós-remoção.
- [ ] Reinstalar e repetir primeiro acesso.
- [ ] Registrar horário, evidência e resultado de cada passo.

Não executar disparo em massa ou usar dados reais de clientes.
